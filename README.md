# Pore Pressure Prediction Using Well-Log Data

## Overview

This repository contains the work developed for a comparative evaluation of conventional and machine learning methods for pore pressure prediction using multi-well wireline log data.

The project focuses on evaluating data-driven approaches for subsurface pressure prediction and exploring their potential application to CO₂ injection assessment.

## Research Objectives

- Review conventional methods used for pore pressure prediction.
- Identify and evaluate relevant wireline log variables for pore pressure prediction.
- Develop machine learning models for pore pressure prediction.
- Compare conventional and machine learning approaches using appropriate evaluation metrics.
- Assess the relevance of predicted pore pressure for CO₂ injection assessment.

## Data

The study uses multi-well wireline log data.

The original datasets are not included in this public repository where redistribution or publication rights have not been established.

## Methodology

The workflow will include:

1. Data quality assessment and preprocessing
2. Exploratory data analysis
3. Selection of relevant input variables
4. Conventional pore pressure prediction
5. Machine learning model development
6. Model evaluation and comparison
7. Interpretation of results for CO₂ injection assessment
